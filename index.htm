TailNG

Scalability of Angular. Simplicity of Tailwind.

A modern Angular 21 component system built with Tailwind CSS — token-based theming, standalone components, and zero lock-in.

Get Started View on npm View on GitHub
Install
yarn add @tailng-ui/ui @tailng-ui/theme @tailng-ui/cdk

Docs and examples live on tailng.dev.

Theming

Token-based themes

Light / dark modes and brand themes using pure CSS variables.

Workflow

Tailwind-first

No abstractions over layout, spacing, or utilities.

Angular

Modern APIs

Standalone components, signals, and modern Angular patterns.

Freedom

No lock-in

Drop TailNG anytime. Your code remains standard Angular.
