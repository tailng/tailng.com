Milestone Roadmap

TailNG roadmap & focus areas

Building a scalable Angular + Tailwind system that stays flexible and theme-safe.

Guiding priorities

  • Token discipline: keep templates mode-safe and theme-friendly.
  • DX: great defaults, minimal ceremony, and predictable patterns.
  • Scalability: components for real apps (forms, data, overlays).
  • No lock-in: avoid runtime and template abstractions.

Focus areas

Theming
  • More semantic tokens and clearer guidance.
  • Improved theme authoring patterns for app developers.
  • Better docs for modes + brand themes.
Forms
  • Date/time inputs, selects, autocomplete improvements.
  • Validation UX patterns and accessibility polish.
  • Composition-first APIs (Tailwind layout control).
Data
  • Table patterns optimized for large datasets.
  • Sorting, pagination, and filtering primitives.
  • "Excel-like" simple UI that stays fast.
Docs & Examples
  • More runnable examples and copy-paste patterns.
  • Component guides: when to use and how to compose.
  • Theme authoring guide for app developers.

Get involved

If you're using TailNG in a real app, feedback on theming, forms, and data components is most valuable.
