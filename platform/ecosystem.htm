Ecosystem

Packages

TailNG is split into focused packages so you can adopt only what you need.

@tailng-ui/ui

npm

Components: Button, Input, Card, Forms, Layout primitives.

@tailng-ui/theme

npm

Tokens + Tailwind preset/plugin for modes and themes.

@tailng-ui/cdk

npm

Utilities and shared primitives used across TailNG packages.

@tailng-ui/icons

npm

Icon component built on @ng-icons/core (peer dependency).

Install
yarn add @tailng-ui/ui @tailng-ui/theme @tailng-ui/cdk

Then follow the docs for Tailwind setup and theming.
